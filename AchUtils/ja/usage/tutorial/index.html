使い方

튜토리얼 시스템

게임 내 튜토리얼을 노드(ScriptableObject) 기반으로 설계합니다. 하드코딩 없이 기획자가 수정 가능하고, 스킵·재진입·저장·복구를 기본 지원합니다.

구조

기본 제공 스텝

스텝설명
HighlightButtonStepUI 요소를 색상으로 강조하고 특정 액션 대기
WaitForActionStep키 이름으로 등록된 플레이어 액션 대기
DialogueStep메시지 패널 표시 + 자동 진행 또는 클릭 대기
DelayStepN초 대기

빠른 시작

1. 씬에 TutorialRunner 추가

2. TutorialSequence 에셋 만들기

Project 창 → 우클릭 → Create → AchUtils/Tutorial/Tutorial Sequence

인스펙터에서 스텝을 추가합니다.

3. 튜토리얼 시작

4. 플레이어 액션 알리기

버튼 OnClick 또는 게임 이벤트 발생 시 호출합니다.

API

TutorialSystem

TutorialRunner

커스텀 스텝 만들기

TutorialStep을 상속하고 Execute를 구현합니다.

저장 방식

PlayerPrefs에 완료된 SequenceId 목록을 콤마 구분 문자열로 저장합니다.

SequenceId를 비워두면 저장되지 않습니다. SaveProgress = false로도 비활성화할 수 있습니다.
