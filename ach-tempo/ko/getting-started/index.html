시작하기

설치하고, 한 바퀴 도는 흐름을 처음으로 가동합니다.

요구 사항

  • Unity 2022.3 이상
  • 외부 의존성 없음 (dependencies: {})

설치

Unity Package Manager → Add package from git URL:

또는 Packages/manifest.json 에 직접:

첫 한 바퀴

빈 GameObject 에 아래 컴포넌트를 붙이면 풀밭에서 불이 번지기 시작합니다.

세 개의 Tick 순서는 반드시 긴장도 → 디렉터 → 월드 입니다. 디렉터는 이번 프레임의 긴장도를 보고 조건을 깔고, 월드는 그 조건을 받아 번집니다.

피격을 긴장도에 반영하기

플레이어가 맞으면 긴장도를 바로 끌어올립니다.

데이터 갈아끼우기

규칙표·동작·기준값은 모두 데이터센터에 들어 있고, 기본값이 있어 설정 없이 동작합니다. 자기 값을 쓰려면 시작할 때 등록만 하면 됩니다.

예제 가져오기

Package Manager → Tempo → Samples → Basic Grass Fire 를 Import 하면 BasicGrassFireDirector 컴포넌트로 긴장도·국면·번짐을 눈으로 볼 수 있습니다.

다음으로

  • 월드 반응으로 번짐 규칙을 더 깊이 봅니다.
  • 디렉터에서 국면과 동작을 커스터마이즈합니다.

개요

디렉터가 조건만 깔면 월드가 받아 상황을 키우는, 긴장 강약 자동 조절 시스템.

월드 반응

불·물·전기가 규칙대로 서로 바뀌고 격자에서 번지는 쪽.
