AchReactive

A domain-agnostic reaction framework that builds all game content from data composition.

AchReactive is a Unity framework that builds all game content — skills, monsters, items, maps, quests, and more — from data composition following the trigger → condition → effect pattern.

Core idea

Domains are infinite, but behaviors (primitives) are finite.

Building a new system for every domain means filling in the domain × behavior matrix each time. AchReactive makes the behavior pool shared by all domains, turning this multiplication into addition. From the second domain onward, it's almost free.

Features

  • Domain-agnostic — a single DataBase<T> handles Skill/Monster/Item/… all of them
  • Source-agnostic — load from anywhere: JSON, CSV, remote, etc. (implement IDataLoader<T> for a new source)
  • Automatic behavior registration — collects [Effect]/[Condition]/[Trigger] methods via reflection, zero wiring
  • UIToolkit authoring tools — create types and data in the editor (no hand-written JSON)
  • Minimal dependencies — just Newtonsoft.Json
