Reactions and default behaviors

The ReactionEngine execution flow and the provided effects, conditions, and triggers.

Execution flow

Run(trigger, data, ctx) iterates over data.reactions and processes each reaction as follows.

The return value is the number of reactions actually executed.

ReactionContext

An effect reads its own arguments from ctx.Params. The engine injects them per item.

Default effects

typeDescriptionparams

The modifier value is one of flat / percent_add / percent_mul. The targets are all of Targets if present, otherwise Target.

Default conditions

Unless otherwise specified, conditions evaluate Target (or Source if absent).

Default trigger guard

Most triggers (on_use, on_hit, on_equip, etc.) fire on the channel name alone, so they have no guard. Only triggers that need a threshold comparison have a guard.

typeDescriptiontriggerParams
on_hp_belowfires only when Source's HP ratio is at or below thresholdthreshold (0~1)

Stat conventions

The default effects/conditions use the following keys (StatKeys). To use a different scheme, register the effect directly to override it.

KeyMeaning
hpcurrent health (resource)
hp_maxmaximum health (denominator for ratio conditions)
atkattack power (modifiers applied)
defdefense (modifiers applied)
