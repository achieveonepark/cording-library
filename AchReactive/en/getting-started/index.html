Getting started

From installing AchReactive to running your first reaction.

Installation

In the Unity Package Manager, choose Add package from git URL and enter the following address.

Or add it directly to Packages/manifest.json.

The requirement is Unity 2021.3 or later. The only dependency is com.unity.nuget.newtonsoft-json, which is installed automatically.

1. Implement the integration boundary

AchReactive does not impose a structure on your game. You only need to implement two interfaces.

  • IEntity — the subject/target of a reaction (characters, monsters, etc.)
  • IWorld — the world boundary for spawning, range queries, etc.

2. Author the data

Define skills as JSON in the reactions format. (You can also build them with the Data Editor instead of writing them by hand.)

3. Assemble and run

Default effects like damage, heal, and add_modifier are provided by the package, so no extra code is required. You can immediately see a working scene in the Basic example under Samples.
