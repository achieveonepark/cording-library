扩展

新动作、新领域、跨领域连接。

添加新动作

路径 A — Attribute（推荐）

只要编写带有 [Effect]/[Condition]/[Trigger] 的静态方法，AutoRegister() 就会 从所有程序集中自动收集。无需接线代码。

签名是固定的。

路径 B — 手动注册

当需要 DI、运行时状态、闭包时使用。

添加新领域

新领域只需一个数据类即可。没有系统代码。

damage/add_modifier 等会直接复用技能已经注册的那些 → 0 行代码。 数据类和 CSV 映射器可以用 Type Designer 生成。

跨领域

当 effect 需要引用其他领域的数据时，不使用自动注册，而是用手动注册 + 闭包捕获 来抓住对应的 DataBase<T>。不使用类型键（typeof）。

建议：自动注册的 effect 只放不了解领域的纯动作，只有需要与领域耦合的 effect 才用手动注册。

AOT (IL2CPP) 注意事项

AutoRegister() 基于反射，因此在 IL2CPP 构建中方法可能会被剥离。 请用 link.xml 保留包含动作方法的程序集。

如果想避免使用反射，也可以只使用路径 B（手动注册）。
