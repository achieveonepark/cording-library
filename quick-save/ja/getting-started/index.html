はじめに

Quick Save のインストールから最初の保存/読み込みまで

事前準備: MemoryPack のインストール

Quick Save は MemoryPack に依存します。まず NuGetForUnity を通じて MemoryPack をインストールしてください。

  1. NuGetForUnity をプロジェクトにインストールします。
  2. Unity メニューから NuGet > Manage NuGet Packages を開きます。
  3. MemoryPack を検索してインストールします。

インストール

Unity Package Manager (UPM) — 推奨

  1. Window > Package Manager を開きます。
  2. 左上の + ボタン → Add package from git URL... を選択します。
  3. 以下の URL を入力して Add をクリックします。

manifest.json を直接編集

Packages/manifest.json の dependencies に追加します。

暗号化が必要な場合は DataProtector パッケージも追加でインストールしてください。DataProtector があると USE_ENCRYPT シンボルが自動的に定義され、UseEncryption()、UseVersion() メソッドが有効になります。詳細は 使い方 › 暗号化 & バージョン管理 を参照してください。
