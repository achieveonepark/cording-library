UI Workspace 사용법

UI Workspace는 씬의 UIView를 시각적으로 관리하는 에디터 창입니다. Tools › AchEngine › UI Workspace 또는 Project Settings › AchEngine › UI Workspace 에서 열 수 있습니다.

초기 설정

1. UIRoot 생성

Project Settings › AchEngine › UI Workspace → UI Root 생성 버튼 클릭.

씬에 아래 계층이 자동으로 생성됩니다.

2. UIViewCatalog 생성

Create › AchEngine › UI View Catalog 로 Catalog 에셋을 생성합니다.

UIRoot 컴포넌트의 Catalog 필드에 드래그합니다.

3. View 프리팹 등록

Catalog에 View 프리팹을 등록합니다.

필드설명
IDShow("이 ID") 로 열 때 쓰는 문자열
PrefabUIView 컴포넌트가 붙은 프리팹
Layer렌더 레이어
Pool Size사전 생성 인스턴스 수 (0 = 필요 시 생성)

View 열기 / 닫기

View 프리팹 만들기

기본 View

Pool 활성화

같은 View를 자주 열고 닫는 경우 Pool을 사용해 GC를 줄입니다.

Catalog의 Pool Size를 1 이상으로 설정하면 닫힐 때 Destroy 대신 Pool로 반환됩니다.

Single Instance

같은 View가 중복으로 열리는 것을 막습니다.

UIBootstrapper 설정

씬 시작 시 자동으로 열 View를 지정합니다.

유용한 컴포넌트

UICloseButton

가장 가까운 부모 UIView를 닫는 버튼입니다. 코드 없이 Inspector에서 연결만 하면 됩니다.

UIOpenButton

버튼 클릭 시 지정한 View를 여는 컴포넌트입니다.

UISafeAreaFitter

노치/펀치홀 영역을 피하는 SafeArea 적용 컴포넌트입니다. UIRoot가 런타임 구조를 초기화할 때 Screen, Popup, Tooltip 레이어 루트에 자동으로 추가합니다. Background와 Overlay는 화면 전체를 덮어야 하므로 Safe Area 적용 대상에서 제외됩니다. 별도 Canvas나 사용자 정의 레이어를 사용할 때만 직접 추가하면 됩니다.

Unity 6 에디터 툴바

Unity 6000.3 이상에서는 메인 툴바의 AchEngine › Scene Navigator에서 Build Settings에 등록된 씬을 바로 선택할 수 있습니다.

  • 드롭다운에 Build Settings 씬 목록과 활성화 여부가 표시됩니다.
  • 이동 버튼을 누르면 현재 편집 씬의 저장 여부를 확인한 뒤 선택한 씬을 엽니다.
  • 편집 씬을 직접 바꾸거나 Build Settings 목록을 수정하면 선택 상태가 자동으로 갱신됩니다.
  • Play Mode 중에는 씬 선택과 이동이 비활성화됩니다.

UI Workspace 창 활용

에디터에서 Tools › AchEngine › UI Workspace 를 열면:

  • 씬의 모든 등록된 View 목록 확인
  • 에디터 플레이 모드에서 View 강제 열기/닫기
  • 레이어별 View 상태 실시간 확인
  • 미등록 UIView 컴포넌트 경고 감지
