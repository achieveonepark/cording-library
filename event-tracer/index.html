Event Tracer#

Event Tracer is a Unity tool for understanding what happened in your game and why. Record events with their data, connect later events to their causes, inspect call stacks, and save a session to revisit or share.

It works in the Unity Editor and Development Builds. The browser lets you search and filter events, follow cause-and-effect links, inspect payload snapshots, and open the code that recorded an event.

Quick start#

Install the package in a Unity 2022.3 or later project. Open Tools → Achieve → Event Tracer, start a session, and add recording points to your game code:

using Achieve.EventTracer;

EventTrace.StartSession("Shop test");
var purchase = EventTrace.Record("Shop.Purchase", new { price = 100 });
EventTrace.Record("Wallet.Spend", new { amount = 100 }, parentId: purchase);

Call recording methods on Unity's main thread. Passing a recorded event ID as parentId links a later event to its cause. When recording from a MonoBehaviour, pass source: this to let the browser select that object.

Enter Play mode and select an event to inspect its data, cause, effects, source object, and calling code.

Guides#

  • Installation: install from OpenUPM or a Git URL.
  • Using the browser: inspect events, capture stacks, and save or reopen sessions.
  • API reference: recording, configuration, snapshots, and capture limits.

Demo#

Import Shop Demo from the package's Samples section in Package Manager, then run Tools → Achieve → Samples → Create Shop Trace Demo. Enter Play mode and click Buy FireSword in the Game view. The demo intentionally charges twice, so select Shop.Purchase in Event Tracer to see its two Wallet.Spend effects.

Use Reset shop / new session in the Game view to start over.
