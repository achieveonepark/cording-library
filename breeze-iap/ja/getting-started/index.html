はじめに

Breeze IAP のインストールと基本設定ガイド

要件

項目バージョン
Unity2022.3 以降
Unity In-App Purchasing5.3.0 以降

インストール

Unity Package Manager (Git URL)

  1. Window → Package Manager を開きます。
  2. 左上の + ボタン → Add package from git URL… をクリックします。
  3. 以下の URL を入力して Add を押します。

com.unity.purchasing 5.3.0 の依存関係は Unity Package Manager が自動的にインストールします。

基本設定

1. 商品リストの定義

App Store Connect / Google Play Console に登録した商品 ID とタイプを InitializeDto の配列として記述します。

ProductType は UnityEngine.Purchasing 名前空間にあります。

2. 初期化

アプリ起動の早い段階で一度だけ InitializeAsync を呼び出します。通常はシーン入場時に最初に実行される MonoBehaviour.Start で呼び出します。

isDebug: true を渡すと Unity コンソールに詳細ログが出力されます。リリースビルドでは省略するか false に設定してください。

初期化は一度だけ — すでに初期化された状態で InitializeAsync を再度呼び出すと、静かに無視されます。

3. 未確定購入の処理

初期化直後に必ず GetPendingList() を呼び出します。前のセッションで購入は完了したが Confirm が呼ばれる前にアプリが終了した場合、その購入がここに含まれています。

GetPendingList() は初期化前に呼び出すと null を返します。

4. 購入

必ず Confirm を呼び出す — アイテム付与後に Confirm を呼ばないと、その購入は次回実行時に GetPendingList() に再び現れます。

エラー処理

PurchaseAsync は失敗しても例外を投げず、常に PurchaseResult を返します。IsSuccess が false の場合、ErrorMessage に失敗理由が含まれます。

状況IsSuccessErrorMessage
購入完了true""
初期化前に呼び出しfalse"初期化失敗"
60 秒タイムアウトfalse"決済タイムアウト"
ストア購入失敗falseストアのエラーメッセージ

初期化中にタイムアウトが発生すると、InitializeAsync は返りますが内部状態は未初期化のまま残ります。その後の PurchaseAsync 呼び出しは即座にエラー結果を返します。
